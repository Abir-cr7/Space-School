 Space School

Space School is an interactive, cinematic 3D scrollytelling web platform built for the NASA Space Apps Challenge. Guided by an animated vector mentor, **Mr. Siuu**, students explore 25+ real NASA Moon and Mars missions through physics-driven rocket launch simulations, authentic archives, and gamified micro-quizzes.

#Key Features
25+ NASA Missions: Journeys covering historic and modern Moon & Mars hardware.
Interactive Mentorship: Guided learning experience led by animated mentor Mr. Siuu.
3D Launch Simulations: Physics-driven simulations powered by interactive web graphics.
Gamified Quizzes & Badges: Micro-quizzes after every mission and a Master Space Explorer final badge.
